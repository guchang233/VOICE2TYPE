# Voice2Type 宣传片

发布会风格（Apple / OpenAI / Anthropic 式：纯黑底、大字排版、极光渐变、真实产品演示）的 68 秒宣传片。
画面全部由代码生成，演示镜头内嵌的是**真实前端**（`src/index.html`），配乐与音效由 `soundtrack.py` 程序化合成，
不含任何第三方素材，可放心商用发布。

| 文件 | 作用 |
|------|------|
| `film.html` | 时间轴合成。每一帧都是 `render(t)` 的纯函数，可在浏览器直接打开预览 |
| `render.mjs` | Playwright 逐帧截图 → ffmpeg 编码 H.264 → 混入配乐 |
| `soundtrack.py` | 合成配乐（D 大调，≈94 BPM）与音效（转场、键盘、点击、打字……），与画面事件逐帧对齐 |
| `out/` | 渲染产物（已 gitignore） |

## 分镜

| 时间 | 场景 | 画面 | 文案 |
|------|------|------|------|
| 0–6s | 冷开场 | 一条声波在黑场中起伏，收拢成文字光标，逐字打出 | 说出来，**就写好了。** |
| 6–11s | Logo | 图标弹出（声纹跳动后归位）、字标、四项能力 | Voice2Type · 语音输入 · 实时字幕 · 语音合成 · 视频配音 |
| 11–23s | 语音输入 | 真实界面：按下 F2 → 录音球变红、声纹跳动 → 松开识别 → 文字出现在聊天输入框并发送 | 按住，**说话。** / 松开，**就写好了。** |
| 23–35s | 实时字幕 | 直播画面中原文逐字上屏（临时态→定稿），英文译文随后跟上；下方实时转录可导出 | 实时字幕，**同声传译。** |
| 35–46s | 语音合成 | 真实界面：输入文本 → 打开音色库、选中「新闻主播」→ 生成 → 波形播放 | 一段文字，**千种声音。** |
| 46–57s | 视频配音 | 六个节点依次点亮：视频输入 → 音频提取 → 字幕识别 → 字幕编辑 → 语音合成 → 混流输出 | 一键，**视频配音。** |
| 57–62s | 主题 | 深色 / 浅色 / 护眼三套界面层叠展开，引擎跑马灯 | 深色，**浅色**，护眼。 |
| 62–68s | 结尾 | Logo、Slogan、开源信息 | 说出来，**就写好了。** · 开源免费 · Windows |

竖屏版的关键信息都放在画面中上部，避开抖音 / 快手右侧按钮栏与底部标题区。

## 渲染

依赖：Node 18+、Playwright（含 Chromium）、ffmpeg（含 libx264）、Python 3 + numpy + scipy，
以及字体 **Noto Sans CJK SC**（含 Black 字重）、**Inter / Inter Display**、**JetBrains Mono**。
Ubuntu 上：`apt install fonts-noto-cjk fonts-noto-cjk-extra fonts-inter fonts-jetbrains-mono`。

```bash
# 在仓库根目录执行
node promo/render.mjs                       # 竖屏 1080×1920 @60fps → promo/out/Voice2Type-launch-9x16.mp4
node promo/render.mjs --landscape           # 横屏 1920×1080 @60fps → promo/out/Voice2Type-launch-16x9.mp4
node promo/render.mjs --stills 3.9,14.2     # 只导出静帧，快速检查画面
node promo/render.mjs --fps 30              # 30fps 版本（文件更小）
```

修改文案或节奏：`film.html` 中每个场景的时间写在 `scene(开始, 结束, …)`；音效时间点在文件末尾的 `ev(...)`，
配乐会自动读取导出的事件表重新合成（加 `--rebuild-audio` 强制重建）。
