本地模型使用教程

1下载转写引擎

点击设置页「转写引擎」区块的「下载引擎」按钮，应用会自动下载 whisper.cpp v1.9.2 纯 CPU 版（whisper-bin-x64.zip，约 8MB）并解压到模型目录下的 whisper-bin 子文件夹。

也可手动下载：点击 whisper.cpp Releases，下载 whisper-bin-x64.zip，解压所有文件到 模型目录/whisper-bin/。

提示：请使用纯 CPU 版（whisper-bin-x64.zip），不要用 BLAS 版（whisper-blas-bin-x64.zip），BLAS 版启动有额外线程池开销。

2下载模型文件

在「Whisper 模型」区块点击对应模型的「下载」按钮，应用内下载（支持断点续传）。CPU 推理速度差异极大，按需选择：

  • tiny — 极快，2秒音频约1秒。日常听写首选 (~75MB)
  • base — 快，2秒音频约2-3秒。精度速度均衡 (~142MB)
  • small — 慢，2秒音频约9秒。需高精度且硬件强 (~466MB)
  • medium — 很慢，2秒音频约20秒+。仅高配机 (~1.5GB)

下载后点击模型卡片上的「使用」按钮设为当前。

3选择并使用

  1. 回到设置，在「语音识别模型 → 整段识别」中选择「本地 Whisper」
  2. 确认模型卡片显示「使用中」
  3. 使用语音输入快捷键录音，松开后将自动调用本地引擎转写

启动后引擎和模型会预热到系统文件缓存，首次转写稍慢，后续更快。本地模型不消耗 API 额度，完全离线运行。
