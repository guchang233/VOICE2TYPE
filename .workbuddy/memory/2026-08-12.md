# 2026-08-12 工作日志

## 新增：Fish Audio 文本转语音（TTS）功能

为 VOICE2TYPE（Tauri 2.0 应用）新增「语音合成」视图，调用 Fish Audio API 将文本转为语音。

### 后端（Rust / src-tauri）
- **config.rs**：新增 `TtsConfig` 结构体（fish_api_key、model、reference_id、reference_title、format、speed、volume、latency、chunk_length、normalize、temperature、top_p、mp3_bitrate、sample_rate），默认 model=`s2.1-pro-free`；加入 `AppConfig.tts`；新增 `tts_config()`/`set_tts_config()` 方法。
- **tts/mod.rs + tts/client.rs**（新模块）：`FishTtsClient` 实现：
  - `synthesize(text, &TtsConfig)` → POST `https://api.fish.audio/v1/tts`，model 通过**请求头** `model` 传递（非 body），返回音频字节。
  - `list_voices(api_key, &VoiceListParams)` → GET `/model`（分页/标题/语言/排序/仅自建）。
  - `get_voice(api_key, id)` → GET `/model/{id}`。
  - 专用 `TTS_HTTP_CLIENT`（300s 超时）。
- **commands.rs**：新增 `tts_synthesize`（合成→写临时文件→返回路径）、`tts_export`（保存对话框→复制试听文件，保证与试听一致）、`tts_list_voices`、`tts_get_voice`。
- **main.rs**：声明 `mod tts`，注册 4 个命令。
- **Cargo.toml**：tauri 增加 `protocol-asset` feature（asset 协议播放本地试听文件）。
- **tauri.conf.json**：`app.security.assetProtocol` 启用，scope `["**"]`。

### 前端（src）
- **index.html**：新增「语音合成」导航项（subtitle 与 history 之间）与 `view-tts` 视图——文本输入、音色卡片+音色库模态（搜索/语言/排序/分页）、参数面板（模型/格式/码率/语速/音量/延迟/温度/TopP/分段/归一化）、API Key、试听播放器、下载按钮。
- **styles.css**：追加 TTS 视图全部样式（双栏布局、滑块、音色卡片、模态、音色网格），适配深色主题，<900px 响应式单栏。
- **app.js**：新增 `initTts()`/`loadTtsView()`/`populateTtsUi`/`collectTtsConfig`/`saveTtsConfigDebounced`/`synthesizeTts`/`downloadTts`/音色库浏览器（`loadVoices`/`renderVoices`/`selectVoice`/`clearVoice`/分页）；`toAssetUrl` 用 `convertFileSrc` 播放本地音频；switchView 进入 tts 时加载配置；防抖保存配置。

### 关键技术点
- Fish Audio TTS 的 model 是**请求头**而非 body 字段。
- 试听→下载采用「复制试听文件」而非重新合成，确保下载内容与试听完全一致。
- 免费模型字符串：`s2.1-pro-free`（S2.1 Pro 免费层）。
